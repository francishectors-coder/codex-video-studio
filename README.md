# Codex Video Studio

AI-powered devotional video production using OpenAI Codex, Python and FFmpeg.

## Features
- 1280x720 YouTube videos
- English and Tamil bilingual captions
- Cinematic scene transitions
- Gentle instrumental background music
- Opening titles and promotional endings
- Automatic MP4 rendering
- Downloadable videos through GitHub Actions

## First Project
Saint Francis of Assisi - 30-second demonstration video.

## Future Goal
Automated 10-minute devotional storytelling videos.

This project is independent of MELODIA AI.
